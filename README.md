# CareConnect

CareConnect is a web platform that connects seniors who need help with volunteers who want to give it. Seniors post help requests, and volunteers browse and claim them.

## Features

- Task board where users post, browse and claim help requests
- Login and registration with a personal request history
- Volunteer registration and verification
- Admin dashboard to manage requests and volunteers
- Feedback and contact forms
- Senior-friendly design with large text, clear navigation and a responsive layout

## Built With

- HTML
- Bootstrap 5
- JavaScript
- Supabase (cloud database)
- Font Awesome icons

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.

The app connects to a Supabase project. To use your own, replace the Supabase URL and key in the script section of `index.html`, and create these tables: `help_requests`, `volunteers`, `feedback` and `contact_messages`.
